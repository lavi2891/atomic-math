## Planning and implementation boundaries

The roadmap is a plan: it does not activate Skills or claim that adaptive placement, the four required arithmetic sprints, geometry rendering, or the complete Grade 8 progression already exist. The executable catalog still includes `AR_PLACE_VALUE`; that implementation fact does not make decimal place-value a core target of the new roadmap. Future curriculum work must reconcile the active path deliberately.

Roadmap priorities run from P5 (highest pedagogical criticality) to P1; the dated audit's engineering P0/P1 issue priorities use a different scale. Earlier taxonomy tables, Topic ratings, adaptive-difficulty proposals and numerical counts in historical documents are not current policy.

The multiplication correction in `01d6cbd4e9b90d754b7035ed8f54914650f1c8e3` is a typography-only change: generated display math is canonicalized separately from evaluator expressions and rendered through the shared KaTeX path. Sampling the pre-fix bank found 47 active definitions emitting asterisks and 30 emitting crosses (77 total); IDs, versions and existing review approvals were preserved because mathematical meaning and assessed content were unchanged. These are dated correction counts, not permanent bank totals.
